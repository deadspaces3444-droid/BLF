## Шаг 2. Бесплатный домен blf.is-a.dev (3 минуты)

Правила is-a.dev: только личные/некоммерческие проекты разработчиков, сайт должен быть доступен, в заявке нужен контакт. BLF подходит: открытый код, без рекламы и оплат.

### 2.1. Форк
Откройте https://github.com/is-a-dev/register/fork и нажмите **Create fork**.

### 2.2. Добавьте файл
В форке: **Add file → Create new file**, имя файла:

```
domains/blf.json
```

Содержимое (можно скопировать целиком):

```json
{
  "owner": {
    "username": "deadspaces3444-droid",
    "email": "deadspaces3444@gmail.com"
  },
  "records": {
    "CNAME": "deadspaces3444-droid.github.io"
  }
}
```

> ⚠️ Замените e-mail на свой, если нужен другой контакт, — в заявке он обязателен.
> Никаких A-записей и «proxied» не нужно: для GitHub Pages нужен именно CNAME на `deadspaces3444-droid.github.io`.

### 2.3. Откройте Pull Request
Кнопка **Contribute → Open pull request** → заголовок `Register blf.json` → тело PR возьмите из файла `DOMAIN-is-a-dev-PR.md` (он лежит рядом).

### 2.4. После мёржа (проверяйте PR, могут попросить правки)
1. В репозитории BLF: **Settings → Pages → Custom domain** → вписать `blf.is-a.dev` → **Save**.
2. Дождаться проверки DNS, поставить галочку **Enforce HTTPS**.
3. Через несколько минут сайт откроется по адресу **https://blf.is-a.dev**, а `deadspaces3444-droid.github.io/BLF` будет перенаправлять на него.

Если ревьюер отклонит имя (занято/зарезервировано) — скажите, подготовлю заявку на другое имя: `blf-pc.is-a.dev`, `sborkapc.is-a.dev`, `blf-build.is-a.dev` (все были свободны).

## Альтернативы, если не хочется PR

| Вариант | Имя | Плюсы | Минусы |
| --- | --- | --- | --- |
| GitHub Pages (уже работает) | `deadspaces3444-droid.github.io/BLF` | 0 минут, HTTPS, бесплатно навсегда | длинный адрес |
| **Cloudflare Pages** | `blf.pages.dev` | бесплатно, HTTPS, свой короткий поддомен, деплой из GitHub | нужен аккаунт Cloudflare (карта не нужна) |
| Netlify / Vercel | `blf.netlify.app`, `blf.vercel.app` | бесплатно, свой поддомен | нужен аккаунт, лимиты трафика |
| is-a.dev | `blf.is-a.dev` | имя «как у настоящего домена», бесплатно навсегда | заявка-PR, ждать ревью |
| Дешёвый настоящий домен | `blf.ru`, `blf-pc.ru` | полностью ваш, можно почту | от ~200–400 ₽/год (не бесплатно) |

Для Cloudflare Pages: **Workers & Pages → Create → Pages → Connect to Git → репозиторий BLF → Framework: None, build command пустой, output `/`**. Получите `blf.pages.dev` без всяких заявок.
