# Website Purpose

<!-- WEBSITE_PURPOSE_START -->
BLF is an open-source, non-commercial PC building web app written in plain JavaScript (no backend, no accounts, no ads, no payments). It lets you configure a PC or a home server from a catalog of ~860 parts, checks compatibility between components, estimates FPS in 20 games, compares parts and builds, filters components by CPU socket, suggests cheaper/faster swaps, and recalculates prices for 1080 Russian cities. It is a free educational tool for people who want to assemble a PC or a home server without paying for consultations. Source code: https://github.com/deadspaces3444-droid/BLF
